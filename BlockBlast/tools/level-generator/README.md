# BlockBlast 关卡生成器

双击 `start.bat`，浏览器会打开 `http://127.0.0.1:5173`。

批量脚本默认生成纯 `gameMode: "match3"` 关卡；网页工具仍可按按钮选择消消乐、Block Blast 或混合模式。

难度按钮会按玩法分别调整棋盘密度、目标分数和可用方块。消消乐配置会输出 `moveLimit`、`colorCount` 与固定的 `matchLength: 4`。Cocos 运行端已经支持相邻交换、无效交换回退、四连消除、下落补充和连续消除。

默认平衡：1–10 关简单、11–50 关中等、51–100 关困难。简单 Block Blast 关卡使用完整棋盘和基础方块；简单消消乐使用完整棋盘、4 色和 34 步。

“自定义关卡范围”可以添加多条规则，例如第 1–5 关简单、第 6–10 关中等。每条规则可以选择通关后不赠送道具、随机赠送一种、赠送指定道具或三种都送，并设置数量。后添加的重叠规则优先。

## 使用方式

1. 选择完整、菱形、圆角或十字预设，或者设置密度和种子后随机生成。
2. 点击任意棋盘格进行手动微调。
3. 设置关卡 ID、目标分数、奖励和可用方块。
4. 下载单个 JSON，或者批量下载 ZIP。
5. 把解压后的 `level_XXX.json` 放入 `assets/resources/levels/`。

也可以进入 `tools/level-generator` 后执行 `npm run generate:levels`，直接重新生成项目内平衡后的 100 关。

`boardMask` 固定包含 8 个字符串，每个字符串包含 8 个字符：

- `1`：可以放置方块。
- `0`：棋盘空洞，不显示格子，也不能放置方块。

没有 `boardMask` 的旧关卡会继续使用完整 8×8 棋盘。
