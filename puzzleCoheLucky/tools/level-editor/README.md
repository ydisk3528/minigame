# 关卡编辑器

双击 `start.bat`，打开 `http://127.0.0.1:5173`。

- 棋盘固定为 8×8，支持完整、菱形、十字、圆角、圆环、沙漏、H、阶梯、双岛以及手工点格。
- `boardMask` 使用 64 位 `0/1`；`0` 不绘制格子，也不会生成或掉落元素。
- 当前玩法按八方向连接同种元素，连接至少 3 个才消除；编辑器会阻止无合法三连结构和少于 3 种元素的配置。
- `propReward` 支持无奖励、随机奖励、指定锤子/魔法棒/刷新/无限道具；只在首次通关时发放。
- “保存到项目”会直接更新 `assets/resources/datas/level.csv`。
- “批量生成关卡”可指定起始关卡和 1–5000 的数量，支持随机/固定形状、3–8 色和每关道具配置；同 ID 数据会在确认后覆盖。
