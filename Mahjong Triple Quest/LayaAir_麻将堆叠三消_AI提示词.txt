请使用 LayaAir 3.x + TypeScript 开发一款完整可运行的 HTML5 竖屏休闲游戏。

# 一、游戏定位

游戏名称暂定：

Mahjong Triple Quest

游戏类型：

麻将题材 + 多层堆叠 + 三张消除 + 道具 + 关卡制

参考玩法：

玩家点击没有被遮挡的麻将牌，麻将牌进入底部槽位。

当底部槽位中出现 3 张完全相同的麻将牌时，自动消除。

底部槽位最多容纳 7 张麻将牌。

如果槽位达到 7 张，并且无法继续触发消除，则本局失败。

注意：

只能参考“多层堆叠 + 底部槽位三消”的玩法结构。

美术、UI、关卡布局、动画、规则细节必须重新设计，不要直接复制任何已有游戏的界面、名称、素材或关卡。

TypeScript

# 五、麻将堆叠系统

每张麻将牌至少包含：

id
type
value
x
y
layer
width
height
blocked
selected
removed

例如：

{
    "id": 101,
    "type": "wan",
    "value": 3,
    "x": 320,
    "y": 450,
    "layer": 2
}

layer 越大，表示层级越高。

需要实现遮挡检测。

如果一张麻将牌的可点击区域被更高层麻将覆盖一定比例，则：

blocked = true

禁止点击。

上层麻将被移除之后：

自动重新计算下面所有麻将牌的 blocked 状态。

# 六、点击麻将

点击可以操作的麻将后：

麻将牌：

1. 轻微放大。
2. 从当前位置飞向底部槽位。
3. 飞行动画时间约 0.15～0.3 秒。
4. 使用 Ease 缓动。
5. 到达底部后自动排列。

不要瞬间移动。

需要有明显的飞牌反馈。

# 七、底部槽位

屏幕底部设计 7 个麻将槽位。

例如：

[ ][ ][ ][ ][ ][ ][ ]

点击麻将后进入槽位。

要求：

同类型麻将自动靠近排列。

例如原本：

一万
三筒
一万

再次加入一万后：

一万
一万
一万
三筒

并播放粒子效果。

# 八、普通三消规则

例如：

红中 + 红中 + 红中

# 十一、道具系统

第一版至少加入 4 个道具。

## 道具1：撤回

功能：

撤回玩家最后一次点击。

将麻将牌从底部槽位重新飞回原位置。

恢复：

x
y
layer
blocked

状态。

每局默认：

3次。

## 道具2：洗牌

重新随机场上尚未消除麻将牌的位置。

要求：

只改变麻将牌分布。
不能改变麻将牌总数量。

洗牌后：

重新计算遮挡关系。

播放麻将牌飞散再重新排列动画。

## 道具3：移出

选择底部槽位中的最多3张麻将。

暂时放入额外区域。

用于腾出槽位。

额外区域可以位于底部槽位下方。

## 道具4：提示

自动高亮：

当前可以形成一组三消的麻将牌。

如果当前没有直接三消：

提示最推荐点击的一张麻将。

提示效果：

麻将牌发光
上下轻微浮动
持续约1秒。
