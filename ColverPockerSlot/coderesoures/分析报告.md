# 100 Blazing Clover 资源与工程还原分析

参考页面：https://jiligames.com/PlusIntro/591?showGame=true
静态资源基址：https://casino-wbgame.jiligames.com/bc100/
采集日期：2026-09-12

## 资源证据

- `src/settings.51fc9.json`：原引擎 Cocos 3.6.2；资源包 game / main / internal；原启动场景 MainGame。
- `assets/game/config.10269.json`：资源类型、原路径、UUID、打包关系和版本号。
- `assets/game/index.10269.js`：公开发布客户端脚本。
- `game-readable.js`：仅解析字符串查找表后保存的阅读辅助版本；没有运行原客户端网络逻辑。
- `manifest.json`：481 个原始静态文件的 URL、大小与 SHA-256；最终下载失败数为 0。

原始文件保持在 coderesoures 下，转换资产独立存放到工程 assets。

## 已确认的玩法数据

- COL=5、ROW=4，共 20 个位置，按列编号。
- WIN_LINE 原始 100 条线路已直接提取到 SlotRules.ts。
- 果实/铃铛/红七、Ladybug Scatter、Clover Wild 符号。
- JP_MULTI = [1000,50,20,5]；CARD_MAX = 3。
- 客户端含翻牌、倍率、移除和收集状态。运行版已实现三同花色奖励、×2/×5 叠乘以及移除所有梅花卡。
- 官方文字 5×3 与其截图和客户端 ROW=4 有冲突，采用客户端数据。

## 恢复方法及产物

将 Cocos 压缩 JSON 的类型表、属性掩码、对象 ID 和 UUID 引用展开。图集按 rect/rotation/offset/originalSize 切分，恢复透明边界，生成 Cocos 3.8.6 图片 meta 和 SpriteFrame 绑定。动画 CCONB 中 TypedArray 转回可编辑动画数据。Spine 二进制、atlas 和对应页纹理单独恢复。

- 397 个 SpriteFrame 图像转换记录（含不同语言、普通/骰子变体）。
- 27 个原始预制体。
- 39 个动画剪辑。
- 18 组 Spine 骨骼资源。
- 37 个音频。
- 4 个新整理的可玩预制体和 1 个启动场景。

场景和可玩预制体中的外部 UUID 引用都可解析。恢复原始预制体时，发布版自定义业务组件被剥离，避免出现 Missing Script；它们的业务能力由 CloverApp 替代。部分原始字体/内置材质/粒子引用没有逐项恢复，相关字体改用系统字体；详见 `tools/recovery-report.json`。这不等于原始预制体所有业务和粒子表现已完整还原。

## 验证界限

执行 Cocos 3.8.6 web-mobile 构建、工程 TypeScript 检查、纯逻辑回归和资源绑定审计，再通过浏览器实际检查本地画面及交互。未做 Android/iOS 真机验证，也没有原版服务端接入。
