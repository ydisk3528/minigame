# 表现还原补充

本轮保留已确认的本地随机与返奖规则，重做动态表现。

## 原客户端证据

`game-readable.js` 可检索以下方法，不需要执行原站网络或服务端逻辑：

- `SpinMoving` / `GetMovelength`：每列四行加上下缓冲，六格循环下移，停轴后两段下压回弹。
- `PlayWin`：Symbol_00～08、Symbol_Wild 使用 Win 动画。
- `PlayAction` / `PlayExpand`：Wild 源行使用 Action_Down / Action_Mid / Action_Top 皮肤；其他行使用原符号皮肤及 Expand。
- `LineMotionStreak` / `SetBones`：WinLine 的 HP_0～HP_6 对应左右边界和五列符号中心。
- `SelectGame_Poker`：Idle、Open_Start、Open_Loop、Remove、Win_Start、Win_Loop、MissOpen_Start。
- `IntroSpine`：GameIntro_L，Open 事件打开主界面。

实际骨骼数据已通过 Cocos 运行时读取并播放：Symbol_Wild 的 Action/Expand 长度 3 秒；各符号 Win 为 1.5 秒；Big/Mega/Super Start 分别 5/8/10 秒，End 为 2 秒；BG_Declare_L 为约 6.67 秒，BG_Compliment Start 为约 8.17 秒。

## 工程接线

`tools/author.py` 序列化预制体、图片、Spine 数据、动画剪辑和控制器引用。每列 Mask 裁切上下缓冲。符号效果使用已绑定骨骼/atlas 的预制体实例，玩法过程中没有用空白节点重新绘制界面。

`CloverApp.ts` 驱动滚轴、符号中奖、扩展、收集、原版连线、大奖计数、入场与翻牌；`ReelMotion.ts` 集中管理滚轴公式与可调时间参数。

兼容修复：Cocos 导入后动画剪辑名称包含文件名 UUID 后缀，播放时解析导入名称；卡牌子节点设为 UI_2D 摄像机可见层；清除原卡牌控制器遗留的子 Button，使用父节点已绑定按钮事件。

原版外部 TempoSetting 的最终时间配置尚未完整提取，目前按客户端运动公式与集中参数运行。不能把本地构建、运行或参数调节声称为原版逐帧对照结果。详细实测见项目根目录 VALIDATION.md。
